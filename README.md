# @turystack/nestjs-logger

Structured logging for NestJS with Pino and pluggable transport adapters. Elasticsearch built-in.

## Installation

```bash
pnpm add @turystack/nestjs-logger
```

### Peer dependencies

The host application provides these:

```bash
pnpm add @nestjs/common @nestjs/core @turystack/nestjs-config reflect-metadata
```

## Documentation

Options, API reference and examples:

**https://tury.dev/libs/nestjs-logger**

## Development

```bash
pnpm install
pnpm typecheck
pnpm check
pnpm test
pnpm build
```
